En Python, une variable est créée par simple affectation. Les types les plus utiles en ingénierie sont les numériques, les chaînes de caractères, les listes et les dictionnaires.

2. Structures de contrôle

Les boucles et conditions permettent d'analyser des séries de mesures, de détecter des anomalies et de générer des rapports d'alarmes automatiquement.

2.1 Conditions — classification de mesures

python
def classifier_temperature(temp):
    if   temp < 0:    return "HORS PLAGE"
    elif temp < 40:   return "BASSE"
    elif temp < 80:   return "NORMALE"
    elif temp < 120:  return "ATTENTION"
    else:             return "⚠ CRITIQUE"

for t in [-5, 25, 65, 95, 135]:
    print(f"{t:6.1f} °C → {classifier_temperature(t)}")

2.2 Boucle for — détection d'alarmes sur 24h

python
pressions = [2.1, 2.3, 2.8, 3.1, 3.4, 3.2,
              3.0, 2.7, 2.5, 2.4, 2.8, 3.1]
SEUIL = 3.0
alarmes = []

for heure, p in enumerate(pressions):
    if p > SEUIL:
        alarmes.append((heure, p))

print(f"{len(alarmes)} alarme(s) détectée(s)")
for h, p in alarmes:
    print(f"  H+{h:02d}h : {p} bar")
⚡

Bonne pratique : nommez les seuils en MAJUSCULES (SEUIL_HAUT = 90.0). Évitez les "nombres magiques" directement dans le code.

3. Fonctions

Une fonction encapsule une logique réutilisable. En ingénierie, on s'en sert pour les conversions d'unités, le traitement du signal, les vérifications de seuils.

python
def calculer_statistiques(mesures, unite="°C", dec=2):
    """
    Statistiques d'une série de mesures capteur.
    Args:
        mesures (list): Valeurs numériques
        unite   (str) : Unité physique
        dec     (int) : Décimales à afficher
    Returns:
        dict: min, max, moyenne, plage
    """
    n   = len(mesures)
    moy = sum(mesures) / n
    return {
        "min"    : round(min(mesures), dec),
        "max"    : round(max(mesures), dec),
        "moyenne": round(moy, dec),
        "plage"  : round(max(mesures)-min(mesures), dec)
    }

temps = [72.1, 75.3, 80.6, 85.4, 83.2]
stats = calculer_statistiques(temps)
print(stats)  # {'min': 72.1, 'max': 85.4, ...}

4. Programmation Orientée Objet

La POO permet de modéliser des objets du monde réel — capteurs, vannes, contrôleurs — en regroupant leurs données et comportements dans une seule entité.

🏭

Analogie industrielle : une classe Python est le schéma (P&ID) d'un capteur. Chaque instance est un capteur physique installé sur le terrain.

python
class Capteur:
    nb_capteurs = 0  # attribut de classe

    def __init__(self, id, unite, seuil_haut):
        self.id         = id
        self.unite       = unite
        self.seuil_haut  = seuil_haut
        self.historique  = []
        Capteur.nb_capteurs += 1

    def lire(self, valeur):
        self.historique.append(valeur)
        if valeur > self.seuil_haut:
            print(f"⚠ ALARME {self.id}: {valeur} {self.unite}")

    def moyenne(self):
        return sum(self.historique) / len(self.historique)

t101 = Capteur("TIC-101", "°C", 90.0)
t101.lire(85.4)
t101.lire(92.1)  # → ⚠ ALARME
print(f"Moy: {t101.moyenne():.2f} °C")

Héritage — CapteurTemperature

python
class CapteurTemperature(Capteur):
    def __init__(self, id, seuil_haut=150.0):
        super().__init__(id, "°C", seuil_haut)

    def en_fahrenheit(self, v): return v * 9/5 + 32
    def en_kelvin(self, v):    return v + 273.15

tc = CapteurTemperature("TT-105")
print(tc.en_fahrenheit(85.4))  # 185.72 °F
